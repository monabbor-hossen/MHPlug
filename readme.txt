A custom Elementor addon with a dedicated dashboard for managing widgets, features, WooCommerce enhancements, and more.

== Description ==

MH Plug is a powerful, lightweight companion suite designed to extend WooCommerce and Elementor. It provides highly optimized, modular features that give you complete control over your store's design and functionality without the bloat. 
Key features include a high-performance WooCommerce Wishlist (cache-friendly, no PHP sessions), custom Elementor widgets (Feature Cards, Synced Sliders, Advanced Headings), fully customizable CSS page preloaders, a built-in Age Gate verification system, and a flexible Theme Builder for custom header/footer templates. Every module is strictly compartmentalized—if you disable a feature, its code is never loaded on your frontend.

== Installation ==

1. Upload the `MHPlug` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **MH Plug** in your WordPress dashboard to enable the widgets and features you need.

== Frequently Asked Questions ==

= Does this require Elementor? =
Yes, the core widgets require Elementor to function. However, some features (like the Preloader and Age Gate) can work independently.

= Does this work with caching plugins? =
Yes. Our wishlist system uses secure first-party cookies to identify guests, completely eliminating the need for PHP sessions that typically break page caching.
